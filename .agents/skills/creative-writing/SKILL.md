# Creative Portfolio Writing & Copywriting Skill

This skill provides guidelines, negative constraints, and structured prompt templates for writing human-sounding, impact-driven portfolio copy (project breakdowns, developer bios, case studies, and tech stack summaries).

---

## 1. Core Principles for Portfolio Content

1. **Impact & Problem-Solving First**: Don't just list technologies used. Explain *what problem was solved*, *why key decisions were made*, and *the measurable outcome/impact*.
2. **Eliminate Generic AI Slop**: AI-generated text often uses predictable filler words and symmetrical sentences. Narrow the constraints before drafting.
3. **Show Technical Ownership**: Clearly communicate your specific role (e.g., "Lead Scripter", "Architected full-stack state management", "Sole Developer").

---

## 2. Anti-AI Slop Rules (Negative Constraints)

Always apply these negative constraints when drafting portfolio text to keep the voice sharp, professional, and authentic:

### 🚫 Forbidden Buzzwords
*   `delve`, `realm`, `harness`, `unlock`, `tapestry`, `beacon`, `cutting-edge`, `revolutionize`, `testament`, `synergy`, `meticulous`, `seamless`, `elevate`, `empower`, `transformative`, `navigating`, `spearheaded`.

### 🚫 Forbidden Clichés & Syntax Patterns
1. **The Symmetrical Negation:** Avoid *"It's not just a project, it's an experience"* or *"Not only X, but also Y."*
2. **Generic Tech Introductions:** Avoid *"In today's fast-paced digital world,"* or *"As a passionate developer driven by innovation..."*
3. **Over-explanation:** Avoid stating obvious developer duties (e.g., *"wrote clean, maintainable code using best practices"*). Show it through concrete architecture details instead.

---

## 3. Writing Frameworks

### A. The Project Showcase Framework (P-A-I)
Use this structure for featured portfolio projects:

- **Problem / Challenge:** What gap existed, or what were the performance/gameplay requirements?
- **Action & Architecture:** What technologies, algorithms, or systems did you build to solve it?
- **Impact / Outcome:** Stats, user engagement, performance benchmarks, or feature delivery success.

### B. Developer Bio & Tagline Rules
- Keep hero taglines under **15 words**. Direct, punchy, memorable.
- Use strong active verbs (*Built*, *Engineered*, *Architected*, *Designed*).
- Combine technical stack with product vision (e.g., *"Full-Stack Developer building responsive web apps and real-time Roblox multiplayer experiences."*).

## 4. Prompt Templates for AI Assistance

### 📋 Template 1: Project Description Refinement
```text
Role: Act as a senior tech editor and copywriter specializing in developer portfolios.
Task: Polish the following project draft.

Draft Input: [PASTE DRAFT HERE]

Rules:
1. Highlight my specific technical contributions and architecture choices.
2. Cut fluff and buzzwords (no "seamless", "cutting-edge", or "delve").
3. Use short, varied sentence structures (burstiness).
4. Limit total length to 3-4 bullet points or a concise paragraph.
```

### 📋 Template 2: Detailed Case Study Draft
```text
Task: Write a portfolio case study for [PROJECT NAME].

Context:
- Technologies: [e.g., Next.js, Luau, Knit, TailwindCSS]
- My Role: [e.g., Head Scripter / Lead Developer]
- Key Features Built: [FEATURE 1, FEATURE 2]
- Technical Challenge Solved: [CHALLENGE]
- Result/Metrics: [e.g., 300+ servers used, 60fps smooth physics performance]

Constraints:
- Follow the Problem -> Action -> Impact structure.
- Write in a confident, pragmatic developer voice.
- Strictly avoid generic AI filler words.
```

---

## 5. Revision & Edit Checklist

Before finalizing any AI-generated portfolio text:
- [ ] **The Read-Aloud Test:** Read the text out loud. Does it sound like how you naturally talk about your code?
- [ ] **Word Audit:** Are any banned words present? Replace them with concrete verbs or metrics.
- [ ] **Specificity Check:** Did you name specific libraries, frameworks, performance stats, or architectural patterns instead of vague claims?
